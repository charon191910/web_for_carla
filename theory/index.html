    🔬 Frenet轨迹规划技术

    Frenet坐标系原理

    Frenet坐标系将复杂的全局路径规划问题转化为沿着道路中心线的局部坐标系问题：

    • s坐标 (纵向): 沿道路中心线的弧长距离
    • d坐标 (横向): 垂直于中心线的横向偏移

    转换公式

    从Frenet坐标(s, d)转换到笛卡尔坐标(x, y)：

    def frenet_to_inertial(s, d, csp):
    ix, iy, iz = csp.calc_position(s)
    iyaw = csp.calc_yaw(s)
    x = ix + d * cos(iyaw + π/2)
    y = iy + d * sin(iyaw + π/2)
    return x, y, iz, iyaw

    优势分析

    1. 降维简化: 将2D规划问题分解为两个1D问题
    2. 约束明确: 道路边界约束变得简单明了
    3. 计算高效: 适合实时轨迹生成
    4. 物理直观: 符合人类驾驶的思维方式

    五次多项式轨迹生成

    项目使用五次多项式来生成平滑轨迹：

    数学模型

    # Quintic polynomial: s(t) = a₀ + a₁t + a₂t² + a₃t³ + a₄t⁴ + a₅t⁵
# Constraints: position, velocity, acceleration at start and end

    系数求解

    基于边界条件求解多项式系数：

    # Start conditions: xs, vxs, axs
# End conditions: xe, vxe, axe
# Time horizon: T

A = [[T³, T⁴, T⁵],
     [3T², 4T³, 5T⁴],
     [6T, 12T², 20T³]]

b = [xe - a₀ - a₁T - a₂T²/2,
     vxe - a₁ - a₂T,
     axe - a₂]

a₃, a₄, a₅ = solve(A, b)

    优化目标

    • 最小化jerk: 确保乘坐舒适性
    • 边界约束: 满足车辆动力学限制
    • 连续性: 位置、速度、加速度连续

    安全性奖励:

    def _compute_safety_reward(self):
    # Collision penalty
    if self.collision_detected:
        return -100.0

    # Safe distance reward
    safe_distance = self._get_safe_distance()
    actual_distance = self._get_front_vehicle_distance()

    if actual_distance < safe_distance:
        return -50.0 * (safe_distance / actual_distance)

    return 10.0 * (actual_distance / safe_distance)

    效率奖励:

    def _compute_efficiency_reward(self):
    # Speed reward
    speed_reward = self.current_speed / self.target_speed

    # Progress reward
    progress_reward = (self.current_s - self.last_s) / self.max_speed

    return 0.6 * speed_reward + 0.4 * progress_reward

    舒适性奖励:

    def _compute_comfort_reward(self):
    # Jerk penalty
    jerk_penalty = -abs(self.current_jerk) * 0.1

    # Acceleration smoothness
    acc_smoothness = -abs(self.acceleration_change) * 0.05

    return jerk_penalty + acc_smoothness

# Training loop

    state = env.reset()
    for step in range(max_steps):
        # Select action
        action = actor.predict(state) + exploration_noise

        # Execute action
        next_state, reward, done, info = env.step(action)

        # Store experience
        replay_buffer.add(state, action, reward, next_state, done)

        # Train networks
        if replay_buffer.size() > batch_size:
            batch = replay_buffer.sample(batch_size)
            train_critic(batch)
            train_actor(batch)

            # Update target networks
            soft_update(target_actor, actor, tau)
            soft_update(target_critic, critic, tau)

        state = next_state
        if done:
            break

    # Shaping rewards to guide learning
def shaped_reward(self, base_reward, state, next_state):
    # Potential-based shaping
    potential = self.compute_potential(state)
    next_potential = self.compute_potential(next_state)

    shaping_reward = base_reward + gamma * next_potential - potential

    return shaping_reward

    网络结构优化

    Actor网络设计

    class ActorNetwork(nn.Module):
    def __init__(self, state_dim, action_dim):
        super().__init__()
        self.fc1 = nn.Linear(state_dim, 256)
        self.fc2 = nn.Linear(256, 128)
        self.fc3 = nn.Linear(128, 64)
        self.fc4 = nn.Linear(64, action_dim)

        # Activation functions
        self.relu = nn.ReLU()
        self.tanh = nn.Tanh()

    def forward(self, state):
        x = self.relu(self.fc1(state))
        x = self.relu(self.fc2(x))
        x = self.relu(self.fc3(x))
        action = self.tanh(self.fc4(x))
        return action

    Critic网络设计

    class CriticNetwork(nn.Module):
    def __init__(self, state_dim, action_dim):
        super().__init__()
        # State pathway
        self.state_fc1 = nn.Linear(state_dim, 256)
        self.state_fc2 = nn.Linear(256, 128)

        # Action pathway
        self.action_fc1 = nn.Linear(action_dim, 128)

        # Combined pathway
        self.combined_fc1 = nn.Linear(256, 64)
        self.combined_fc2 = nn.Linear(64, 1)

        self.relu = nn.ReLU()

    def forward(self, state, action):
        state_feat = self.relu(self.state_fc1(state))
        state_feat = self.relu(self.state_fc2(state_feat))

        action_feat = self.relu(self.action_fc1(action))

        combined = torch.cat([state_feat, action_feat], dim=1)
        combined = self.relu(self.combined_fc1(combined))
        value = self.combined_fc2(combined)

        return value

    📚 数学基础

    强化学习理论

    Markov Decision Process

    MDP = (S, A, P, R, γ)

where:
- S: State space
- A: Action space  
- P: Transition probability P(s'|s,a)
- R: Reward function R(s,a,s')
- γ: Discount factor

    Bellman Equation

    # Value function
V(s) = max_a [R(s,a) + γ * Σ_s' P(s'|s,a) * V(s')]

# Q-function
Q(s,a) = R(s,a) + γ * Σ_s' P(s'|s,a) * max_a' Q(s',a')

    优化理论

    Policy Gradient

    # Policy gradient theorem
∇J(θ) = E[∇_θ log π(a|s) * Q^π(s,a)]

# Actor update
θ_actor ← θ_actor + α * ∇_θ log π(a|s) * A(s,a)

# Critic update (TD error)
δ = r + γ * Q'(s', μ'(s')) - Q(s,a)
θ_critic ← θ_critic - β * ∇_θ (δ^2)

    Lyapunov Stability

    # Lyapunov function for safety
V(x) = x^T * P * x

# Stability condition
dV/dt = ∇V * f(x) ≤ 0

# Constrained optimization
minimize: J(θ)
subject to: E[V(s)] ≤ V_max  # Safety constraint
