    RL-Frenet轨迹规划在CARLA自动驾驶仿真平台

    🎯 项目背景与意义

    为什么需要这个项目？

    随着自动驾驶技术的快速发展，如何让AI智能体在复杂的真实交通环境中安全、高效地学习驾驶技能成为一个重要挑战。传统规则基础的驾驶系统面临以下局限：

    • 适应性差: 难以应对所有可能的交通场景
    • 扩展性弱: 新增场景需要重新编写大量规则
    • 泛化能力有限: 对未见过的场景处理困难

    解决方案

    本项目结合了深度强化学习和Frenet轨迹规划的优势：

    1. 强化学习: 让AI通过试错自主学习最优驾驶策略
    2. Frenet坐标系: 将复杂的空间规划问题分解为纵向和横向两个维度
    3. CARLA仿真: 提供真实的物理环境和多样的交通场景

    项目价值

    • 安全性验证: 在仿真环境中安全地训练和测试驾驶策略
    • 算法研究: 为自动驾驶算法研究提供标准化测试平台
    • 教学示范: 直观展示AI如何学习复杂驾驶任务

    🚗 项目概述

    这是一个基于深度强化学习(Deep Reinforcement Learning)和Frenet轨迹规划的自动驾驶仿真项目。项目使用CARLA模拟器作为仿真环境，通过强化学习算法训练智能体(agent)学会在复杂的交通场景中自主驾驶，并结合Frenet坐标系下的最优轨迹规划技术实现安全、平稳的车辆控制。

    🔬 核心技术详解

    1. Frenet轨迹规划技术

    Frenet坐标系原理

    Frenet坐标系将复杂的全局路径规划问题转化为沿着道路中心线的局部坐标系问题：

    • s坐标 (纵向): 沿道路中心线的弧长距离
    • d坐标 (横向): 垂直于中心线的横向偏移

    这种转换的优势： - 降维简化: 将2D规划问题分解为两个1D问题 - 约束明确: 道路边界约束变得简单明了 - 计算高效: 适合实时轨迹生成

    五次多项式轨迹生成

    项目使用五次多项式来生成平滑轨迹：

    # quintic polynomial: s(t) = a₀ + a₁t + a₂t² + a₃t³ + a₄t⁴ + a₅t⁵
# 确保位置、速度、加速度的连续性和平滑性

    多项式系数求解基于边界条件： - 起点和终点的位置、速度、加速度约束 - 确保轨迹满足车辆动力学限制 - 优化目标：最小化jerk（加速度变化率）

    最优轨迹选择流程

    1. 轨迹采样: 生成多条候选轨迹
    2. 安全评估: 碰撞检测、车道保持
    3. 效率评估: 行驶时间、速度平滑性
    4. 舒适性评估: 加速度、jerk指标
    5. 综合评分: 加权选择最优轨迹

    2. 深度强化学习框架

    状态空间设计

    • 车辆状态: 位置、速度、加速度、航向角
    • 环境感知: 周围车辆信息、交通信号
    • 传感器数据: 摄像头图像、激光雷达点云（可选）
    • 任务目标: 目标位置、期望速度

    动作空间设计

    • 连续动作: 方向盘转角、油门/刹车
    • 离散动作: 变道决策、超车行为
    • 混合动作: 连续控制+离散决策

    奖励函数设计

    # 多目标奖励函数
reward = w₁ × safety_reward + w₂ × efficiency_reward + w₃ × comfort_reward + w₄ × lane_keeping_reward

where:
- safety_reward: 碰撞惩罚、安全距离奖励
- efficiency_reward: 速度奖励、时间效率
- comfort_reward: 加速度平滑性、转向平稳性
- lane_keeping_reward: 车道保持奖励

    算法实现特点

    • DDPG: 适用于连续动作空间，确定性策略
    • PPO2: 样本效率高，训练稳定
    • TRPO: 保证策略改进的单调性
    • A2C: 并行训练，收敛速度快

    2. 深度强化学习算法

    • DDPG (Deep Deterministic Policy Gradient): 适用于连续动作空间的算法
    • PPO2 (Proximal Policy Optimization): 稳定的策略优化算法
    • TRPO (Trust Region Policy Optimization): 保证策略更新稳定性的算法
    • A2C (Advantage Actor-Critic): 高效的Actor-Critic框架

    3. OpenAI Gym接口

    • 标准化环境接口，便于集成各种强化学习算法
    • 支持多场景、多智能体仿真

    🚀 快速开始

    安装步骤

    1. 克隆项目 bash git clone https://github.com/MajidMoghadam2006/RL-frenet-trajectory-planning-in-CARLA.git cd RL-frenet-trajectory-planning-in-CARLA/

    2. 安装依赖 bash pip3 install -r requirements.txt

    3. 安装强化学习算法包 bash cd agents/reinforcement_learning pip install -e .

    CARLA服务器设置

    1. 下载CARLA 0.9.9.2 从CARLA releases page下载预编译版本

    2. 启动CARLA服务器 (终端1) bash ./CarlaUE4.sh -carla-server -fps=20 -world-port=2000 -windowed -ResX=1280 -ResY=720 -carla-no-hud -quality-level=Low

    3. 安装CARLA Python包 bash conda create -n carla99 conda activate carla99 sudo apt-get install python-setuptools cd PythonAPI/carla/dist easy_install --user --no-deps carla-X.X.X-py3.7-linux-x86_64.egg

    训练与测试

    训练示例

    基础配置训练:

    python main.py --cfg_file experiments/tools/cfgs/experiment_baseline.yaml --agent_id 1 --num_timesteps 1e7

    改进配置训练:

    python main.py --cfg_file experiments/tools/cfgs/experiment_improved.yaml --agent_id 2 --num_timesteps 1e7

    测试示例

    自动检测最佳模型:

    python main.py --test --agent_id 1

    指定模型测试:

    python main.py --test --agent_id 1 --test_model best_1000000

    2D可视化模式:

    python main.py --test --agent_id 1 --play_mode 1

    3D可视化模式:

    python main.py --test --agent_id 1 --play_mode 2

    ⚙️ 配置文件说明

    项目支持多种实验配置:

    • experiment_baseline.yaml: 基线实验设置
    • experiment_improved.yaml: 改进的实验设置
    • experiment_lyapunov.yaml: 基于Lyapunov稳定性的设置

    配置文件包含: - 环境参数(CARLA服务器设置) - 算法超参数(学习率、折扣因子等) - 奖励函数设计 - 神经网络结构 - 训练参数(时间步数、批量大小等)

    • 多任务场景: 跟车、变道、路口通行等

    📊 性能评估体系

    1. 安全性指标

    • 碰撞次数: 与障碍物、其他车辆、行人的碰撞统计
    • 车道偏离频率: 非意图的车道偏离事件
    • 安全距离保持率: 与前车保持安全距离的时间比例
    • 紧急制动次数: 危险情况下的急刹车频率
    • 交通规则遵守率: 红绿灯、让行标志等遵守情况

    2. 效率指标

    • 平均速度: 相对于限速的百分比
    • 任务完成时间: 从起点到终点的总时间
    • 行驶距离: 实际路径与最优路径的比值
    • 燃油效率: 基于加速度模型的能耗估算
    • 交通流畅度: 对周围交通流的影响

    3. 舒适性指标

    • 加速度分布: 纵向和横向加速度的统计特性
    • jerk指标: 加速度变化率，影响乘坐舒适性
    • 转向平滑性: 方向盘转角的连续性和平稳性
    • 速度波动: 速度的方差和标准差

    4. 综合评分系统

    overall_score = 0.4 × safety_score + 0.3 × efficiency_score + 0.3 × comfort_score

where each component is normalized to [0, 1] range
