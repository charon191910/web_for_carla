    安装与使用指南

    🔧 系统要求

    硬件要求

    • 操作系统: Windows 10/11 或 Linux (Ubuntu 18.04+)
    • 处理器: Intel i7 或 AMD Ryzen 7 以上
    • 内存: 16GB RAM 以上 (推荐 32GB)
    • 显卡: NVIDIA GTX 1080 或 RTX 2070 以上
    • 存储: 至少 50GB 可用空间
    • CUDA: 支持 CUDA 10.0 以上 (用于GPU加速)

    软件要求

    • Python: 3.7 - 3.9 (CARLA兼容性最佳)
    • CUDA: 10.0 - 11.0 (如果使用GPU)
    • Git: 用于版本控制
    • Conda: Python环境管理

    📦 安装步骤

    1. 基础环境准备

    创建Conda环境

    # 创建Python 3.7环境
conda create -n carla_rl python=3.7

# 激活环境
conda activate carla_rl

# 安装基础依赖
conda install -c conda-forge numpy scipy matplotlib pandas jupyter

    安装PyTorch

    # GPU版本 (推荐)
conda install pytorch torchvision torchaudio cudatoolkit=10.2 -c pytorch

# CPU版本 (仅用于学习)
conda install pytorch torchvision torchaudio cpuonly -c pytorch

    2. CARLA模拟器安装

    下载CARLA

    # 推荐使用CARLA 0.9.9.2
# 从官网下载: https://github.com/carla-simulator/carla/releases/tag/0.9.9.2

# 下载预编译版本
wget https://carla-releases.s3.eu-west-3.amazonaws.com/Linux/CARLA_0.9.9.2.tar.gz

# 解压到指定目录
tar -xzf CARLA_0.9.9.2.tar.gz -C ~/carla/

    安装CARLA Python API

    # 进入CARLA PythonAPI目录
cd ~/carla/PythonAPI/carla/dist

# 查找最新的egg文件
ls carla-*.egg

# 安装CARLA Python包 (根据Python版本选择)
pip install carla-0.9.9-py3.7-linux-x86_64.egg

# 测试安装
python -c "import carla; print('CARLA version:', carla.__version__)"

    🚀 快速开始

    启动CARLA服务器

    基本启动命令

    # 进入CARLA目录
cd ~/carla

# 启动CARLA服务器 (无显示模式，适合服务器)
./CarlaUE4.sh -carla-server -fps=20 -world-port=2000 -quality-level=Low

# 或启动带显示模式
./CarlaUE4.sh -carla-server -fps=20 -world-port=2000 -windowed -ResX=1280 -ResY=720 -carla-no-hud

# 常用参数说明:
# -carla-server: 以服务模式启动
# -fps=20: 设置仿真频率
# -world-port=2000: 设置端口
# -quality-level=Low: 低质量(更快)
# -carla-no-hud: 不显示HUD界面

    验证服务器状态

    # 在Python中测试连接
python -c "
import carla
client = carla.Client('127.0.0.1', 2000)
world = client.get_world()
print('CARLA server connected successfully')
print('Current map:', world.get_map().name)
"

    常用配置选项

    环境配置

    ENV:
  CARLA:
    host: "127.0.0.1"  # CARLA服务器IP
    port: 2000  # 世界端口
    tm_port: 8000  # 交通管理器端口
    resolution: [1280, 720]  # 显示分辨率
  SIM:
    fps: 20  # 仿真帧率
    synchronous_mode: true  # 同步模式
    weather: "ClearNoon"  # 天气条件
  SCENE:
    map: "Town04"  # 地图名称
    traffic_density: 0.3  # 交通密度
    num_walkers: 10  # 行人数量

    算法配置

    AGENT:
  POLICY:
    NAME: "DDPG"  # 支持: DDPG, PPO2, TRPO, A2C
    NETWORK:
      type: "MLP"  # 网络类型: MLP, CNN, LSTM
      hidden_dims: [256, 128, 64]
      activation: "relu"
  TRAIN:
    num_timesteps: 1000000
    learning_rate: 0.001
    batch_size: 64
    gamma: 0.99
    tau: 0.005
    exploration:
      type: "OU"  # Ornstein-Uhlenbeck噪声
      sigma: 0.2
      theta: 0.15

    奖励函数配置

    REWARD:
  weights:
    safety: 0.4
    efficiency: 0.3
    comfort: 0.2
    lane_keeping: 0.1
  params:
    safe_distance: 20.0  # 安全距离(m)
    target_speed: 30.0  # 目标速度(km/h)
    max_acceleration: 3.0  # 最大加速度(m/s^2)
    max_jerk: 5.0  # 最大jerk(m/s^3)

    结果分析

    性能指标计算

    # analysis.py 示例
import json
import pandas as pd

def analyze_results(agent_id):
    # 读取训练数据
    monitor_data = pd.read_csv(f'logs/agent_{agent_id}/monitor.csv')

    # 读取训练摘要
    with open(f'logs/agent_{agent_id}/training_summary.json', 'r') as f:
        summary = json.load(f)

    # 计算关键指标
    metrics = {
        'total_timesteps': len(monitor_data),
        'final_reward': monitor_data['r'].iloc[-1],
        'mean_reward': monitor_data['r'].mean(),
        'std_reward': monitor_data['r'].std(),
        'training_time': summary['training_duration'],
        'best_model_step': summary['best_model_step']
    }

    return metrics

# 分析多个智能体
for agent_id in [1, 2, 3]:
    metrics = analyze_results(agent_id)
    print(f"Agent {agent_id}: {metrics}")

    安装问题

    Python包冲突

    # 问题: 包版本冲突
# 解决: 使用干净的虚拟环境
conda deactivate
conda remove -n carla_rl --all
conda create -n carla_rl python=3.7
conda activate carla_rl

# 重新安装
pip install -r requirements.txt

    CARLA连接失败

    # 问题: 无法连接到CARLA服务器
# 检查1: 服务器是否运行
ps aux | grep CarlaUE4

# 检查2: 端口是否开放
netstat -tuln | grep 2000

# 检查3: 防火墙设置
# Linux:
sudo ufw allow 2000/tcp
sudo ufw allow 8000/tcp

# Windows: 在防火墙中开放端口

    GPU相关问题

    # 问题: GPU内存不足
# 解决1: 减少批量大小
# 在配置文件中设置:
AGENT:
  TRAIN:
    batch_size: 32  # 从64减少到32

# 解决2: 清理GPU内存
# 关闭不必要的程序
# 或使用CPU模式
CUDA_VISIBLE_DEVICES=-1 python main.py --agent_id 1

# 检查GPU使用
nvidia-smi

    训练问题

    收敛困难

    # 问题: 训练不收敛
# 解决1: 调整学习率
AGENT:
  TRAIN:
    learning_rate: 0.0001  # 降低学习率

# 解决2: 增加探索
AGENT:
  TRAIN:
    exploration:
      sigma: 0.3  # 增加探索噪声

# 解决3: 奖励函数调整
REWARD:
  weights:
    safety: 0.6  # 增加安全权重
    efficiency: 0.2

    📈 性能优化建议

    硬件优化

    • 使用SSD: 提高数据加载速度
    • 增加内存: 减少交换空间使用
    • 高性能GPU: 加速神经网络计算
    • 多核CPU: 支持并行环境

    软件优化

    • 批处理: 提高GPU利用率
    • 数据预加载: 减少IO等待时间
    • 模型量化: 减少内存占用
    • 混合精度: 加速计算

    算法优化

    • 课程学习: 从简单到复杂
    • 经验回放: 优先重要样本
    • 并行训练: 多个环境实例
    • 迁移学习: 复用已有知识

    🔍 调试技巧

    环境调试

    # 检查环境状态
env = gym.make('CarlaGymEnv-v1')
obs = env.reset()
print("Observation keys:", obs.keys())
print("Action space:", env.action_space)

# 逐步执行
for step in range(100):
    action = env.action_space.sample()  # 随机动作
    obs, reward, done, info = env.step(action)
    print(f"Step {step}: reward={reward:.2f}")

    if done:
        obs = env.reset()
env.close()

    奖励函数调试

    # 打印奖励分解
def debug_reward(env):
    # 获取各项奖励
    safety_reward = env._compute_safety_reward()
    efficiency_reward = env._compute_efficiency_reward()
    comfort_reward = env._compute_comfort_reward()

    print(f"Safety: {safety_reward:.2f}, "
          f"Efficiency: {efficiency_reward:.2f}, "
          f"Comfort: {comfort_reward:.2f}")
